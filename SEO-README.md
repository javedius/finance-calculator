# SEO Оптимизация - Финансовый калькулятор

## 🎯 Реализованные SEO улучшения

### ✅ 1. Техническая SEO
- **Метаданные**: Расширенные title, description, keywords для всех страниц
- **Open Graph**: Карточки для социальных сетей (Facebook, VK, Telegram)
- **Twitter Cards**: Оптимизация для Twitter
- **Canonical URLs**: Предотвращение дублирования контента
- **Robots.txt**: Автоматическая генерация через Next.js
- **Sitemap.xml**: Автоматическая генерация карты сайта

### ✅ 2. Структурированные данные (JSON-LD)
- **WebApplication**: Основное приложение
- **SoftwareApplication**: Для каждого калькулятора
- **FAQPage**: Часто задаваемые вопросы
- **BreadcrumbList**: Навигационные цепочки

### ✅ 3. Контентная оптимизация
- **SEO-контент**: Дополнительные разделы с ключевыми словами
- **FAQ секции**: Ответы на популярные вопросы
- **Внутренняя перелинковка**: Связанные калькуляторы
- **Хлебные крошки**: Улучшение навигации

### ✅ 4. Производительность
- **Lazy loading**: Отложенная загрузка изображений
- **Preloading**: Предзагрузка критических ресурсов
- **Core Web Vitals**: Мониторинг метрик производительности
- **Оптимизация изображений**: Автоматическая оптимизация

### ✅ 5. Аналитика и отслеживание
- **Google Analytics 4**: Отслеживание пользователей
- **Yandex Metrica**: Российская аналитика
- **События калькуляторов**: Отслеживание использования
- **SEO метрики**: Мониторинг позиций

## 🚀 Следующие шаги

### 1. Настройка аналитики
Замените заглушки на реальные ID:
```typescript
// В app/layout.tsx
<GoogleAnalytics measurementId="G-REAL-ID" />
<YandexMetrica counterId="REAL-ID" />
```

### 2. Создание изображений
Создайте следующие изображения:
- `/public/og-image.jpg` (1200x630px) - для социальных сетей
- `/public/screenshot.jpg` - скриншот главной страницы
- `/public/ndfl-screenshot.jpg` - скриншот НДФЛ калькулятора
- `/public/mortgage-screenshot.jpg` - скриншот ипотечного калькулятора

### 3. Настройка домена
Обновите URL в метаданных:
```typescript
// В app/layout.tsx
metadataBase: new URL('https://your-domain.com'),
```

### 4. Верификация поисковых систем
Добавьте реальные коды верификации:
```typescript
verification: {
  google: 'your-google-verification-code',
  yandex: 'your-yandex-verification-code',
},
```

## 📊 Мониторинг SEO

### Google Search Console
1. Добавьте сайт в GSC
2. Загрузите sitemap.xml
3. Настройте мониторинг Core Web Vitals
4. Отслеживайте позиции по ключевым запросам

### Yandex Webmaster
1. Добавьте сайт в Яндекс.Вебмастер
2. Загрузите sitemap.xml
3. Настройте мониторинг индексации
4. Отслеживайте позиции в Яндексе

### Ключевые запросы для отслеживания
- "финансовый калькулятор"
- "налоговый калькулятор"
- "ипотечный калькулятор"
- "НДФЛ калькулятор"
- "кредитный калькулятор"
- "страховые взносы калькулятор"
- "транспортный налог калькулятор"
